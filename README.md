# Competitive Programming Task Preparation Skill

AI workflow for preparing competitive-programming tasks and packages for Polygon and CMS.

---

# Skill description

* `cp-polygon/`

  * Used to make Polygon packages.

  * Makes files such as generators, validators, checkers, interactors, ..., and commit the package to Polygon via [polyman](https://github.com/HamzaHassanain/polyman).

* `cp-cms/`

  * Used to make CMS packages.

  * Makes files such as graders, stubs, checkers, managers, and sample graders.

---
# Usage

1. Load the skills depending on your usage.
2. Call the skill in the directory that you will be building your packages with your task statement and prompts.
